Proyecto 12. Devoluciones y logística inversa con análisis de causa raíz  (EQUIPO 02)
 
Objetivos: Crear una plataforma para registrar devoluciones, inspeccionar productos, autorizar reembolsos y detectar causas recurrentes. El sistema deberá:
 
Vincular devoluciones con ventas.
Capturar evidencias.
Clasificar motivos.
Determinar disposición del producto.
Coordinar recolección.
Gestionar reembolso.
Detectar patrones.
Asignar responsabilidad.
 
Problema a resolver: Las devoluciones suelen tratarse como casos aislados. Sin embargo, varias devoluciones pueden provenir del mismo lote, proveedor, empaque, ruta o tienda. La solución deberá conectar evidencia no estructurada con información transaccional para detectar problemas sistémicos.
